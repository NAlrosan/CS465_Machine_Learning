# Lab3 – Logistic Regression

Lab exercise implementing logistic regression for binary classification.

## 📄 Contents

- `Lab3.ipynb` – notebook implementing the logistic regression model
- `Lab3Data.txt` – dataset used for training/testing
- `Logistic_Regression_Tutorial.docx` – accompanying tutorial/reference document

## 🔍 What's covered

- Loading and preparing the classification dataset
- Building the design matrix
- Implementing and optimizing a logistic regression model with `scipy.optimize`

## 🛠️ Technologies

- Python
- NumPy
- Matplotlib
- SciPy (`scipy.optimize`)
