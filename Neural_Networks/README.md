# Lab5 – Neural Networks

Lab exercise applying a neural network classifier to the wheat seeds dataset.

## 📄 Contents

- `Lab5.ipynb` – notebook implementing the neural network classifier
- `wheat-seeds.txt` – dataset (seed measurements and variety labels)
- `Neural_Network_Guide.docx` – accompanying guide/reference document

## 🔍 What's covered

- Loading and preparing the wheat seeds dataset
- Training a neural network classifier
- Evaluating accuracy with `sklearn.metrics`

## 🛠️ Technologies

- Python
- NumPy / Pandas
- Scikit-learn
