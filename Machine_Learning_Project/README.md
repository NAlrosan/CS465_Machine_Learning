# Machine Learning Project

An end-to-end machine learning project predicting used car prices, from data preparation through model comparison.

## 📄 Contents

- `Machine_Learning_Project.ipynb` – full project notebook

## 📊 Dataset

[Saudi Arabia Used Cars Dataset](https://www.kaggle.com/datasets/turkibintalib/saudiarabia-used-cars-dataset) — suitable for multiple machine learning tasks including price prediction.

## 🔍 What's covered

- **Data Preparation** – loading, deduplication, and missing-value checks
- **Exploratory Data Analysis (EDA)** – price distribution analysis, identifying right-skew and outliers
- **Feature Engineering** – selecting features based on EDA, variance, and domain knowledge (e.g. engine size, car age)
- **Model Building** – four regression models implemented and compared:
  - Linear Regression
  - Neural Network
  - Decision Tree
  - XGBoost Regressor
- **Model Evaluation** – visual and quantitative comparison of predicted vs. actual values across all models
