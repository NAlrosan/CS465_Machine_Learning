# Lab6 – Decision Trees

Lab exercise on decision tree and ensemble classification applied to a diabetes dataset.

## 📄 Contents

- `LAB6_Machine_Learning.ipynb` – notebook implementing the classifiers
- `diabetesDataset.csv` – dataset used for training/testing
- `DT.pdf` – accompanying decision tree lab handout

## 🔍 What's covered

- Data preprocessing (`LabelEncoder`, `StandardScaler`)
- Train/test split
- Decision tree classification with `DecisionTreeClassifier`
- Ensemble comparison with `RandomForestClassifier`

## 🛠️ Technologies

- Python
- Pandas / NumPy
- Scikit-learn
