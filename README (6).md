# Machine Learning Projects

A collection of mini-projects, labs, and coursework covering core Machine Learning concepts — exploratory data analysis, regression, classification, decision trees, and full end-to-end model building and evaluation.

## 📁 Projects

| Project | Description |
|---|---|
| [EDA Machine Learning](./EDA_Machine_Learning) | Exploratory data analysis on a used-car pricing dataset, including distribution and correlation analysis |
| [Lab2 – Multivariate Linear Regression](./Lab2) | Multivariate linear regression with gradient descent and feature engineering |
| [Lab3 – Logistic Regression](./Lab3) | Logistic regression for binary classification, implemented from scratch |
| [Lab5 – Neural Networks](./Lab5) | Neural network classifier applied to the wheat seeds dataset |
| [Lab6 – Decision Trees](./Lab6) | Decision tree and ensemble classification on a diabetes dataset |
| [Machine Learning Project](./Machine_Learning_Project) | End-to-end regression project predicting used car prices: EDA, feature engineering, and model comparison (Linear Regression, Neural Network, Decision Tree, XGBoost) |

## 🛠️ Main Technologies

- Python
- Jupyter Notebook
- Pandas / NumPy
- Scikit-learn
- XGBoost
- Matplotlib / Seaborn

## 📌 About

These projects were created to practice and demonstrate core Machine Learning concepts, algorithms, and workflows, from data preprocessing and EDA through model building and evaluation.
