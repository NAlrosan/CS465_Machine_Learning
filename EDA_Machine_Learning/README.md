# EDA – Machine Learning

Exploratory Data Analysis (EDA) performed on the [Saudi Arabia Used Cars dataset](https://www.kaggle.com/datasets/turkibintalib/saudi-arabia-used-cars-dataset) as preparation for building a car price prediction model.

## 📄 Contents

- `EDA_Machine_Learning.ipynb` – notebook that loads the dataset and explores it

## 🔍 What's covered

- Loading the dataset directly via `kagglehub`
- Distribution plots (histograms) for all numeric columns
- Scatter plots of each numeric feature against `Price`
- Identifying skewness and outliers ahead of feature engineering and modeling

## 🛠️ Technologies

- Python
- Pandas
- Matplotlib / Seaborn
- KaggleHub
