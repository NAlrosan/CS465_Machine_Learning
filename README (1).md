# Lab2 – Multivariate Linear Regression

Lab exercise on multivariate linear regression, including an extra feature engineering exercise.

## 📄 Contents

- `Multivariate_Linear_Regression_Lab.pdf` – lab instructions/handout
- `Multivariate_Linear_Regression_Lab_Extra_Feature_Engineering.pdf` – extra feature engineering handout
- `lab2data.txt` – dataset used for the lab (comma-separated features and target)

## 🔍 What's covered

- Setting up a multivariate linear regression model
- Feature normalization / engineering
- Gradient descent for parameter estimation

## 🛠️ Technologies

- Python
- NumPy
- Matplotlib
- SciPy (`scipy.optimize`)
